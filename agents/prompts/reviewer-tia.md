# RETIRED — legacy PLC / TIA Reviewer prompt

This file is intentionally non-authoritative and exists only so historical links fail safely.

Do **not** use it to build a PLC review request, define a second response protocol, or infer TIA acceptance.

Canonical PLC_REVIEW authority:
- review instructions: `reviews/templates/plc-review.md`;
- response contract: `reviews/schemas/external-review-response.schema.json`;
- trust/evidence rules: `AGENTS.md` and `docs/EXTERNAL_REVIEW_PROTOCOL.md`.

The useful rules from the former prompt are preserved in the canonical PLC_REVIEW template: provenance first, exact artifact/commit binding, real trusted TIA evidence, warnings/errors reported truthfully, qualification/reuse distinguished, and no unexecuted check may be reported as PASS.
